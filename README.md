# Student Information System

A simple web-based Student Information System built for a Capstone project using PHP, MySQLi, and CSS.

## Features
- **User Authentication:** Secure Login and Logout system (`login.php`, `logout.php`).
- **Full CRUD Operations:** Add, view, edit, and delete student records seamlessly.
- **Optional Middle Name Support:** Handles student middle names with automatic "N/A" defaults.
- **Print-Ready Dashboard:** Includes custom print styling (`@media print`) to generate clean physical copies or PDF printouts of the student directory without UI clutter.

## Tech Stack
- **Backend:** PHP (MySQLi)
- **Database:** MySQL (`student_info_system`)
- **Frontend:** HTML5, CSS3
- **Server:** XAMPP / Apache
